# Example Slippi replays

User-supplied replay files retained as reference inputs for development.
Their presence does not mean they have all been parsed or playback-validated.

Generated recordings and validation artifacts belong in ignored run directories,
not this curated collection.

The original 28 fixtures are tracked. New/bulk `.slp` imports stay ignored;
adding another curated fixture requires an explicit `git add -f`. The V100 now
has 3,326 local replay files, including doubles that the singles catalog skips.
See [the corpus inventory and next data steps](../../docs/replay-corpus.md).
